Tu taller de apps, en el bolsillo.

Le dices a Claude Code qué app quieres, con tus palabras, y Bolsillo la construye y la ejecuta en tu propio teléfono. Con su base de datos, sin PC y sin servidores ajenos: el código es tuyo.

📲 Instalar Código en GitHub

Necesitas una cuenta de Claude Pro o Max, o una clave de API.

De una idea a una app en un minuto

El vídeo es una grabación real: se pidió una app de gastos con base de datos y Claude Code la hizo en 1 min 20 s.

  1. Pide

    «Una app para apuntar mis gastos, con el total del mes bien grande». Sin saber programar.

  2. Claude Code la construye

    Escribe el código dentro del Linux de tu móvil, lo comprueba y te cuenta qué ha hecho.

  3. Úsala

    Se abre a pantalla completa y puedes ponerla en el inicio como cualquier app. ¿Algo que cambiar? Díselo.

Instalar

Dos formas, según tu teléfono.

Lista para usar

🤖 Android

  • Android 8 o superior, 64 bits, ~1,5 GB libres.
  • La primera vez prepara su Linux (Ubuntu en proot): unos minutos con conexión.
  • Después arranca en segundos, y tus apps funcionan sin conexión. Claude sí necesita internet para crearlas o cambiarlas.
Descargar la APK

🍏 iPhone (Safari)

  • Sin instalar nada: un Linux aarch64 entero se ejecuta dentro de Safari (QEMU compilado a WebAssembly).
  • Arranca desde una instantánea con Linux y Claude Code ya cargados, y el inicio de sesión está guiado en el chat.
  • Necesita un servidor propio que sirva el disco y dé red al Linux. Está en pruebas.
Cómo montarlo

Preguntas

¿Necesito saber programar?

No. Describes la app y Claude Code la escribe. Si quieres, el código está ahí para mirarlo o tocarlo.

¿Qué cuenta de Claude necesito?

Una suscripción Pro o Max (inicias sesión desde la propia app) o una clave de API de Anthropic.

¿Dónde se guardan mis apps y sus datos?

En tu teléfono. En Android, en la carpeta de Bolsillo. En la versión de Safari, además se hace una copia en el servidor que tú montes, para recuperarlas al volver a abrir la página.

¿Funcionan sin conexión?

En Android, sí: las apps corren en el Linux del móvil. En Safari, de momento, no: la página y la red del Linux pasan por el servidor.
