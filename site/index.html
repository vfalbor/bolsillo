Your app workshop, in your pocket.

You tell Claude Code what app you want, in your own words, and Bolsillo builds it and runs it on your own phone. With its database, no PC and no third-party servers: the code is yours.

📲 Install Code on GitHub

You need a Claude Pro or Max account, or an API key.

From an idea to an app in a minute

The video is a real recording: we asked for an expenses app with a database and Claude Code made it in about 2 minutes.

  1. Ask

    "An app to log my expenses, with the month's total nice and big." No coding needed.

  2. Claude Code builds it

    It writes the code inside your phone's Linux, checks it and tells you what it did.

  3. Use it

    It opens full screen and you can put it on your home screen like any app. Something to change? Just say so.

Install

Two ways, depending on your phone.

Ready to use

🤖 Android

  • Android 8 or later, 64-bit, ~1.5 GB free.
  • The first time it sets up its Linux (Ubuntu in proot): a few minutes online.
  • After that it starts in seconds, and your apps work offline. Claude does need internet to create or change them.
Download the APK
Experimental

🍏 iPhone (Safari)

  • Nothing to install: a whole aarch64 Linux runs inside Safari (QEMU compiled to WebAssembly).
  • It boots from a snapshot with Linux and Claude Code already loaded, and sign-in is guided in the chat.
  • It needs your own server to serve the disk and give Linux its network. Still being tested.

Questions

Do I need to know how to code?

No. You describe the app and Claude Code writes it. If you want, the code is there to look at or tweak.

Which Claude account do I need?

A Pro or Max subscription (you sign in from the app itself) or an Anthropic API key.

Where are my apps and their data kept?

On your phone. On Android, in Bolsillo's folder. In the Safari version, a backup is also kept on the server you set up, to restore them when you reopen the page.

Do they work offline?

On Android, yes: the apps run on the phone's Linux. On Safari, not for now: the page and the Linux network go through the server.
