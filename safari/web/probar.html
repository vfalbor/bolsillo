Cada opción arranca un Linux arm64 con Claude Code dentro de Safari. Si Safari se queda sin memoria, recargará la página sola: eso también es un resultado. El servidor guarda cómo fue cada intento.

1 · RecomendadaChat con Claude. Arranca desde una instantánea con Linux y Claude ya cargados: la más rápida. 2 · LigeraChat con Claude pidiendo menos memoria, por si Safari recarga la página con la 1 (arranca en frío: tarda más). 3 · TerminalLa pantalla de terminal de Claude en vez del chat (más lenta al escribir).
  1. Empieza por la 1. La barra de arriba dice cuánto falta para el Linux y para Claude. Si Safari recarga la página, usa la 2.
  2. Se abre en Chat: pulsa «Iniciar sesión» nada más abrir (no hace falta esperar al Linux): abre claude.ai, autoriza, copia el código y pulsa «Pegar código» y escribe tus prompts abajo; se le pasan a Claude al pulsar Enviar.
  3. La pestaña Debug enseña todo lo que pasa por detrás; el servidor lo recibe cada 5 s.
  4. Si funciona, prueba la siguiente. Al acabar, no hace falta que me copies nada.
